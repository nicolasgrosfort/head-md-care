# Design observation — "My Exercise" game

- Discovered the game *My Exercise* in the evening. Initially found boring, then became engaged.
- Key observations:
  - **Possibility of playing as the dog** — inhabiting a non-human body.
  - **Possibility of cheating** (doing more reps than required) — the game trusts the player.
  - **Micro-juiciness:** Small tactile details (the dog struggling to get up, needing longer presses) make the experience feel alive.
  - These observations inform how the project should approach physical interaction and small feedback moments.
