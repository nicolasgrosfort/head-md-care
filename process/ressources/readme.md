# Ressources

Contains all visual, interactive, and conceptual references used in this project.

## Structure

The various project examples should have this structure:

```md 
---
date: [date]
url: [url]
description: [a brief description of the project]
why: [why this project is relevant to our project]
---

# Images

![Image description](path/to/image.png)
![Image description](path/to/image.png)

# Notes

...
```

The filename should be in the format `YYYY-MM-DD-title-of-the-project.md`.
